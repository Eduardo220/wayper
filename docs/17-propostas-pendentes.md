# Propostas Pendentes

Este arquivo guarda propostas que precisam de aprovação humana antes de qualquer implementação.

Nada registrado aqui pode ser implementado sem aprovação humana explícita. Proposta não é decisão oficial.

## Status possíveis

- Proposta
- Aprovada
- Rejeitada
- Adiada
- Implementada

## Formato obrigatório

```md
## [Título da proposta]

Status:
Data:
Origem:
Área afetada:

### Contexto

### Problema

### Solução proposta

### Impacto no produto

### Impacto técnico

### Arquivos prováveis

### Documentação que precisa mudar

### Riscos

### Alternativas

### Recomendação da IA

### Decisão humana
```

## Como usar

- Use este arquivo para propostas concretas que já têm solução sugerida.
- Se a entrada ainda for só uma ideia, registre primeiro em [[16-ideias-de-melhoria]].
- Se a proposta virar decisão técnica, registre também em [[08-decisoes-tecnicas]].
- Se a proposta afetar produto, GPS, território, ranking ou Firestore, valide também contra [[10-decisoes-do-projeto]].
